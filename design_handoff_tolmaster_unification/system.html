Refined TolMaster — same UI, unified language.

Nothing about the layout, content, or information density has changed. What changed is the discipline behind the visual atoms: one radius scale, one button system, one badge system, one card chrome. Status is communicated by a single mechanism (a thin accent stripe + a small badge), not by tinting whole cards. Accent colour is reserved for primary action, focus, and selected state — never decoration.

06 Five rules to keep things tight
1 Predict-the-radius rule

Before writing rounded-[…], ask: is this interactive (r-2), a container (r-3), or an inline tag (r-1)? If none, you probably shouldn't be drawing it.

2 Status lives in two places

A stripe on the card edge and a badge on the top-right. Never tint the entire card. Yield, Cpk, validity — all use this same channel.

3 Accent earns its weight

If accent appears in more than 4 places on a screen, you've made it noise. Reserve it for: primary CTA, focus state, selected tab, μ line.

4 One focus, one ring

Every focusable thing — buttons, inputs, selects, toggles, radio — uses the same --ring on focus. No border-thickness changes.

5 No off-scale values

If a padding feels wrong on the 4px grid, fix the layout, not the value. py-1.5 mixed with py-2 is the source of most "visual jitter."

6 Header is chrome, not a slide

The dark bar at the top is a system surface. It uses muted text and ghost buttons, never large brand statements or decorative pills.
